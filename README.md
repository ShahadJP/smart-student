# Smart Student Hub
🔗 **[افتح الموقع مباشرة](https://shahadjp.github.io/smart-student/)**

منصة طلابية تشمل حجز الساعات المكتبية، مشاركة الملخصات، الإعلانات، ولوحة تحكم للمشرف
.
برنامج التطوير بالذكاء الاصطناعي
برنامج تدريبي عملي لتعلّم كيف تستخدم الذكاء الاصطناعي لبناء مشروعك البرمجي من الصفر، بمهارة تقدر تطبّقها بأي أداة وفي أي مكان.



# 1. استكشاف الفكرة

**المشكلة:** تشتت الخدمات الطلابية بين عدة منصات وصعوبة الوصول إليها.

**الحل:** إنشاء منصة **Smart Student Hub** تجمع الموارد الدراسية والفعاليات وحجز المواعيد في مكان واحد.

---

# 2. التخطيط والمتطلبات

**المتطلبات:**

* صفحة رئيسية.
* صفحة موارد دراسية.
* صفحة فعاليات.
* صفحة حجز مواعيد.
* لوحة تحكم للإدارة.

**الخطة:**

1. تحليل المشكلة.
2. تصميم الواجهة.
3. تطوير الموقع.
4. اختبار المشروع.

---

# 3. تطوير الحل

تم تطوير الموقع باستخدام:

* HTML
* CSS
* JavaScript

ويحتوي على خمس صفحات رئيسية لتسهيل الخدمات الطلابية.

---

# 4. الاختبار والتحسين

**تم اختبار:*

*
☑ التنقل بين الصفحات.

☑ نموذج الحجز.

☑ عرض البيانات في لوحة التحكم.

**مشكلة ظهرت:**
عدم ظهور الحجوزات.

**الحل:**
استخدام Local Storage لحفظ البيانات.

**تحسينات مستقبلية:**

* قاعدة بيانات.
* تسجيل دخول.
* إشعارات بريد إلكتروني.

---

# 5. التوثيق والتسليم

**قبل:** الخدمات متفرقة وصعبة الوصول.

**بعد:** جميع الخدمات في منصة واحدة.

**التقنيات المستخدمة:** HTML, CSS, JavaScript.

---

# كيف ساعد الذكاء الاصطناعي؟

* اقتراح فكرة المشروع.
* تصميم الواجهة.
* إنشاء الأكواد.
* اكتشاف بعض الأخطاء وتحسينها.
